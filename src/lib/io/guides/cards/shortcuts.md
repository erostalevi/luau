# ⌨️ Shortcuts

The one to remember: **⌘⇧P** opens the command palette. Every action is there, with its shortcut.

## Everywhere

| Keys     | Action                      |
| -------- | --------------------------- |
| ⌘⇧P      | Command palette             |
| ⌘P       | Quick open a card or board  |
| ⌘N       | New card                    |
| ⌘T       | Open a board                |
| ⌘⇧F      | Search                      |
| ⌘⇧E      | Explorer                    |
| ⌘B       | Show or hide the side panel |
| ⌘Z / ⌘⇧Z | Undo / redo                 |
| ⌘\       | Split the view              |
| ⌘,       | Settings                    |

## On a board

| Keys          | Action             |
| ------------- | ------------------ |
| Arrows        | Move the selection |
| Enter / Space | Open / peek        |
| ⌥ + arrows    | Move the card      |
| Tab / ⇧Tab    | Nest / un-nest     |
| ⌘D            | Duplicate          |
| F2            | Rename             |
| ⌘⌫            | Archive            |

## In the editor

| Keys     | Action                |
| -------- | --------------------- |
| `/`      | Slash menu            |
| ⌘E       | Live preview / source |
| ⌘K / ⌘⇧K | Web link / card link  |
| ⌘⌥1–3    | Heading 1–3           |
| ⌘⇧V      | Paste as plain text   |

On Windows and Linux use Ctrl instead of ⌘. Change any shortcut, or switch to the VS Code, Trello, Vim or Emacs presets, in **Settings → Keyboard shortcuts**.
