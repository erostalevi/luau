# 🖼 Images and files

Attach a file by **dragging it into the editor**, **pasting** it, or with `/file` in the slash menu. Luau copies it next to the card, so the board folder stays self-contained.

## Images

![A pastel sunset]({{asset:sunset.svg}})

Set the width after a `|` in the alt text, or drag the corner of an image to resize it:

![Luau icon|120]({{asset:luau.png}}) ![Luau icon|80]({{asset:luau.png}}) ![Luau icon|48]({{asset:luau.png}})

Images on the same line sit side by side and wrap when the editor is narrow.

## PDFs

PDFs show their first page:

![Quick reference|240]({{asset:quick-reference.pdf}})

Click the thumbnail to open the file in your PDF app.

## Other files

Any other file is a normal link: [quick-reference.pdf]({{asset:quick-reference.pdf}}). Images from the web work too, as `![alt](https://…)`.

> [!tip] Card covers
> Right-click a card on the board and pick **Set cover…** to show one of its images on the card face. Try it on this card.
