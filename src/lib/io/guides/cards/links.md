# 🔗 Links and embeds

## Links to other cards

Type `[[` and start writing a title: Luau suggests matching cards and can create a new one. Once picked, the link stores the card's id, so it keeps working after you rename or move the card.

- A link: [[{{card:text}}]]
- With a custom label: [[{{card:tables}}|the tables card]]
- To a heading: [[{{card:text}}#Emphasis]]

Click a link to open the card. `⌘[` and `⌘]` go back and forward.

## Embeds

Put `!` in front to show another card _inside_ this one:

![[{{card:embedMe}}]]

## Web links

- With a label: [Markdown guide](https://commonmark.org/help/)
- Plain URLs become links by themselves: https://tauri.app
- Web links open in your browser.
- Add the title `"preview"` to show a link as a small preview card: `[Tauri](https://tauri.app "preview")`. Luau fetches the page title and image for you.

## Files

Link a file next to the card like any other link: [the quick reference]({{asset:quick-reference.pdf}}). Clicking it opens the file in its default app. See [[{{card:images}}]].
