# 📊 Tables

Tables render as you type. Insert one from the slash menu (`/table`) or write it by hand:

| Feature   | Syntax         | Shortcut |
| --------- | -------------- | :------: |
| Bold      | `**text**`     |    ⌘B    |
| Italic    | `*text*`       |    ⌘I    |
| Highlight | `==text==`     |   ⌘⇧H    |
| Card link | `[[Title]]`    |   ⌘⇧K    |
| Web link  | `[label](url)` |    ⌘K    |

## Alignment

Colons in the separator line align a column:

| Left      | Center | Right |
| :-------- | :----: | ----: |
| a         |   b    |     1 |
| long text | middle | 1 000 |

Tables show on the card face too, so they are handy for small status overviews.
