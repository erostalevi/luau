# 🏷 Tags and mentions

## Tags

Write `#` and a word anywhere: #guide #idea #design/ui

- Type `#` to pick from the tags you already use.
- Tags show as colored chips on the card face.
- Slashes make nested tags: #design/ui and #design/brand both belong to #design.

## Mentions

Write `@` and a name: @ana and @sam reviewed this.

- Type `@` to pick a name you already used.
- People listed under `assignees:` in the [[{{card:properties}}]] footer appear on the card face.
- Set your own name in Settings (⌘,) so **Filter: my cards** and **Assign to me** work.

## Find them later

Search (⌘⇧F) for `tag:guide` or `mention:ana`. See [[{{card:search}}]].
