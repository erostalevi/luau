## 1. Critical (data loss or app hang)

1. 🔬 **Deadlock after ~60 s of continuous typing in one card.**
   - Where: `crates/lull-core/src/app/mod.rs` `apply()` keeps the board mutex locked, then calls `note_edit` → `write_edit` → `self.board(..).lock()`. `parking_lot` mutexes are not re-entrant.
   - Reproduced: one edit per second; edit #60 (t = 61 s) never returned.
   - Effect: the board's RPCs hang, the watcher thread blocks (no external-change handling for any board), and quit hangs.
2. 🔬 **Trash purge can delete folders outside the board.**
   - Where: `store/trash.rs` `purge()` takes `e.id` from the *contents* of `entry.json`, without validating it. An unparseable `deletedAt` counts as expired. Purge runs automatically on `open_board`.
   - Reproduced: a crafted `.lull/trash/t000001/entry.json` with `"id": "<abs path>"` made opening the board **`remove_dir_all` a folder outside it**.
   - Risk: any downloaded, synced or cloned board. `Restore` has the same unvalidated-id pattern (📖).
3. 🔬 **Edits are lost if you close the editor within the autosave delay (300 ms).**
   - Where: `src/lib/editor/Editor.svelte` `onDestroy`. `flushAndSeal()` awaits `resolveTitleLinks()` while `view` is already set to null, so `save()` returns early.
   - Reproduced: typed text, pressed Esc at once, and nothing was saved. With a 1 s pause before Esc it was saved.
4. 📖 **Switching cards in place can write card A's text into card B.**
   - Where: `Editor.svelte` `save()` reads the *live* `boardId`/`cardId` props after they have already changed to B, while `view` still holds A.
   - Triggers: ⌘[ / ⌘], ⌥⇧↑/↓, or the pinned sidebar following the selection, within 300 ms of typing.
5. 📖 **Loading rewrites a corrupt or half-written `board.json`.**
   - Where: `store/mod.rs` writes a fresh manifest, losing name, kind (Files → Kanban), lane order, colors and view.
   - This also happens on read-only paths: watcher reload, `io.inspect`, rescan.
   - Danger: iCloud, Dropbox or git writing non-atomically.
   - 🔬 In my harness, a corrupt `board.json` made open fail with a misleading **"not a board"**. There was no backup and no recovery prompt.

## 2. High

6. 📖 **The file RPCs accept any path from the webview.**
   - Affected: `json.read/write`, `text.write`, `bytes.write`, `path.exists`, `attachment.add {path}`, `io.export dest`, `settings.import`.
   - One XSS could therefore write `~/.zshrc` or a LaunchAgent, or copy `~/.ssh/id_rsa` into a board and read it back over `lull://`.
   - The markdown pipeline itself looked safe (html:false, mermaid strict, KaTeX trust off), so this is defence-in-depth, but it matters for ISO 27001.
7. 📖 **Two concurrent undo/redo calls can panic.** `peek_undo` and `take_undo().unwrap()` are under separate locks. Release builds use `panic = "abort"`, so this crashes the whole app.
8. 📖 **The unlinked-attachment sweep moves files that are still referenced.** It misses `<img>`/`<video>` HTML, `lull://` refs, references from other cards, and cards that failed to read (e.g. iCloud-evicted). It runs on every open.
9. 🔬 **Card operations get slower as the board grows.**
   - Cause: every create, move or trash inside a lane sets `ch.lanes = true` (`store/mod.rs` `touch_parent`), so `index_changes` re-reads and re-indexes **every card** while holding the board lock.
   - Measured (release build):

| Board size | Create per card | 2000 cards total |
|---|---|---|
| 400 cards | 4.7 ms | — |
| 2000 cards | **48 ms** | 97 s |

   - About 50 % of the time is `save_container` (each `atomic_write` does `sync_all`, which is F_FULLFSYNC on macOS), and about 35 % is the SQLite re-index.
10. 📖 **Keyboard and DnD issues.**
    - Letter shortcuts use `e.code`, so on AZERTY ⌘Z closes the tab.
    - AltGr on Windows Spanish/German layouts is swallowed (`mod+alt+1/2/3`, `mod+alt+n`).
    - `kb.recording` is never reset if you leave the Keybindings view while recording, so all shortcuts stay dead until reload.
    - DnD swallows the first click after a drop, and it never handles `pointercancel`/blur, so a drag can get stuck.
11. 📖 **Default bindings point to commands that don't exist yet:** `remote.transition/assign/comment/pull/push`, plus Trello preset `board.filterMine` and `card.assignSelf`. Integrations should add the `remote.*` ones. Please check after that merge.

## 3. Medium

- 📖 `code.run` trust is decided by the webview. `code.trust "*"` has no native confirmation, and a malformed `board` param becomes `"*"`.
- 📖 `settings.import` accepts security-sensitive keys: `editor.python` (any binary), `ai.endpoint` (any host gets card text), and `trash.ttlDays: 0` (immediate purge, not clamped).
- 📖 The `lull://` block on `.lull/` can be bypassed with `%5C` or `.%2F%2F`, which serves trash and history. It also follows symlinks and serves `.git/` on regular boards.
- 📖 Kind rules are checked only at the top level. `Place{Root}` or a nested `Batch` on a kanban board puts cards at the root, and they disappear on reload.
- 📖 Opening a copy of a board with the same id silently replaces the open original in memory.
- 📖 External edits can be lost. Undo stacks survive reload, and the 2.5 s self-echo window ignores real external saves.
- 📖 A failed undo/redo pops the entry anyway, so the step is lost.
- 📖 Basic (non-LLM) card summaries are always empty, because `meta.plain` is cleared by the indexer, and the empty result is cached.
- 📖 `lull://` reads whole files into memory, starts one thread per request, and keeps an unbounded thumbnail cache (every `w` value).
- 📖 Editor and UI issues:
  - Esc in a confirm dialog also closes the modal editor underneath.
  - The pinned sidebar editor can't be closed; it re-opens immediately.
  - `modalOpen` ignores QuickInput, Dialogs, FirstRun and Cheatsheet, so global shortcuts fire behind them.
  - Undo can target the sidebar board instead of the focused tab.
  - A false "external change" banner can appear when switching cards.
  - Tab drag-reorder lands one slot too far right in the same pane.
  - Natural-date conversion fires inside code and link labels (`arr[now]`, `[sat](url)`).
  - Rich paste runs turndown inside code blocks (escapes `*_#`, loses indentation).
  - Opening attachments and "Open settings.json" can't work in the packaged app: `opener:allow-open-path` is missing from the capabilities.
  - "Paste as plain text" uses `navigator.clipboard`, which shows the WKWebView paste bubble.
  - "Move to new window" loses non-board tabs.
  - Links in AI summaries and embeds are dead (`target=_blank` isn't routed to the browser).
  - `priority: High` renders as the literal "priority.High" in the properties widget.

## 4. Low and UI polish

- 🔬 The search placeholder is cut off at the default sidebar width ("Search cards and docume…").
- 🔬 The search syntax help is one long run-on paragraph; a 2-column table would read better. The chip `updated:>=…` shows a `⩾` ligature from JetBrains Mono.
- 🔬 Settings → Language: at ~800 px the segmented control overlaps its description ("Interface … language."). The category "Local AI & summa…" is truncated.
- 🔬 Opening the card editor shows an empty white sheet for ~200 ms before content appears.
- 🔬 `[[` card-link autocomplete didn't appear in my run (typed `[[Butt`). This may be timing in the mock; please check in the native app.
- 🔬 The browser mock ignores `tag:`/`board:` filters (dev-only), so search in `pnpm dev:web` looks unfiltered.
- 📖 The Cheatsheet doesn't close with Esc (never focused). FirstRun has no focus trap or Esc. Dialogs and QuickInput don't trap Tab.
- 📖 Mermaid keeps its old theme after a light/dark switch.
- 📖 Native menu events go to every window when none is focused, so actions run once per window.
- 📖 A few strings bypass i18n: window-control aria labels and native menu labels (English only).
- 📖 Rust:
  - `history::prune` is never called, so blobs grow forever.
  - `history.query` with a date-only `to` excludes that day.
  - Range header bugs in `lull://` (`bytes=-N`, 416 cases).
  - The watcher debounce can starve under continuous events.
  - The cross-board move map is never pruned.
  - Blocking file I/O inside async fns (summaries, code runner, web preview).
- 📖 CSP `img-src https: http:` lets remote tracking pixels load in cards. All windows can read the clipboard (capability).
- 🔬 Tooling:
  - `pnpm lint` is broken: no `eslint.config.*`, and Prettier is missing the svelte plugin config, so 128 files are unformatted. CI doesn't run lint.
  - `pnpm audit`: `lodash-es` via mermaid (1 high, 1 moderate); fixed in ≥ 4.18.1.
