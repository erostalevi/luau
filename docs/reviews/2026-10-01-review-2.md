## 5. Findings in this round

1. **Medium (UX), not fixed: first discovery waits on macOS privacy prompts.**
   - With the default root (the home folder), the first scan reaches `~/Desktop`, `~/Documents` and
     `~/Downloads`, and macOS asks for access ("Luau would like to access files in your Desktop folder").
   - The discovery thread blocks until someone answers, and the status bar shows "Indexing boards 0/…" the
     whole time.
   - First-run explains this, but nothing signals that the app is waiting.
   - **Proposal:** scan the protected folders last (or only after the user opts in on first run), and show
     "Waiting for folder access…" while a prompt is open.
   - *Note:* that prompt was still open on your screen when I finished. I did not answer it; it belongs to you.
2. **Low:** card faces repeat a trailing tag-only line ("…in Slack. #history") as both text and a chip. The
   preview text could drop trailing tag-only lines.
3. **Info:** window-by-id captures of transparent macOS windows lose the vibrancy behind them (grey background,
   black status bar). This is a capture artefact, not an app bug. With "Reduce transparency" the captures are
   exact.
4. **Fixed during this pass:** a missing space in the start page activity list ("New· Pasta" → "New · Pasta").

## 6. Not verified in this pass (needs a human or credentials)

- **Native input:** I could not send clicks or keys to the native window (no Accessibility permission), so drag
  and drop, typing, menus, dialogs and native file pickers were only checked in the web build, which uses the same
  frontend.
  - Please try once in the desktop app: drag a card; open a folder (the dialog grants the path); attach a file;
    open an attachment; trust a board and run a Python cell (native prompt); "Move tab to new window".
- **External services:** Jira, Trello and Slack (real accounts), Ollama or LM Studio (local AI), and OS
  notifications.
- **Gatekeeper:** the app is ad-hoc signed, so other Macs will block it until it is signed with a Developer ID
  and notarized (`APPLE_*` secrets in the release workflow).
- **Updater:** the endpoint is still the `OWNER` template. The app now says "updates are not set up" instead of
  failing. Set the real GitHub repo before the first release.

## 7. Known trade-offs (documented)

- **Saving on macOS:** uses `fsync` instead of `F_FULLFSYNC`. Files are never left half-written, but a power loss
  can lose the very last save. This made saving about 100× faster.
- **Code cells:** they run with your user's permissions once you trust a board. There is no sandbox.
- **Old app data:** `~/Library/Application Support/app.lull.desktop` from builds made before the rename is left
  in place. It can be deleted.
